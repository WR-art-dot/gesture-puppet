产品需求文档 · v0.3 · 2026-11-10

小熊看见你 Bear Sees You

一个用摄像头手势操纵角色表情的网页。你摆姿势、动手指，屏幕里戴熊头罩的小熊立刻用表情和小动作回应你。

01项目定位

  • 一句话：打开链接、允许摄像头，小熊就"活"了——视线追着你的手，你握拳它生气，你张开手它咧嘴笑。
  • 目标用户：拿到链接的任何人，零学习成本，举起手就能玩。
  • 使用场景：笔记本前置摄像头，桌面或手机浏览器，单人短时间互动（几十秒到几分钟）。
  • 发布目标（已确认）：发给朋友玩。手机端前置摄像头体验是正式验收项，不是"顺手检查"。
  • 运行方式：纯静态网页，无账号、无服务器、无安装。所有识别计算在本机浏览器内完成。托管必须 HTTPS（浏览器对摄像头 API 的强制要求）。

02核心体验：打开后的 30 秒

用户视角分镜
  1. 打开链接。米白纸感舞台上，小熊正在轻轻呼吸、每隔几秒眨一次眼——没有任何手势它也活着。
  2. 页面提示"请允许使用摄像头"，附一句话解释：画面只在本机处理，不上传。
  3. 授权后，用户把手举到镜头前：小熊眼睛立刻转向手的方位，头微微偏过去，像被打扰到的好奇小动物。
  4. 用户张开五指：小熊的嘴角随张开程度连续咧开，五指全张时已经是大笑。
  5. 用户握拳：眉毛倒竖、嘴嘟起、腮红加深，头顶冒出怒气符号。
  6. 用户竖大拇指：小熊单眼 wink，嘴角一侧上挑，得意 3 秒。
  7. 手离开画面：小熊视线缓缓回中，3 秒后回到待机状态（走神、眨眼）。
体验的关键质感来自三点：跟随必须即时（150ms 内起反应）、动作必须平滑（弹簧插值，无跳变）、角色必须始终有微动作（呼吸和眨眼不能停）。

03手势清单

手势分两类。连续控制：参数每帧跟随手的变化；离散触发：摆出姿势并稳定保持约 0.2 秒才触发，避免识别抖动导致表情乱跳。

手势类型小熊的反应优先级
手在画面中移动连续瞳孔与视线追手，头部朝手的方向微转P0
手掌倾斜（左右转）连续头跟着歪，角度与手掌一致（上限 ±12°）P0
单手五指张开程度连续嘴形在"抿嘴微笑"到"张嘴大笑"之间连续变化P0
握拳离散生气嘟嘟：倒眉、嘟嘴、腮红加深、怒气符号，手势保持期间锁定该表情P0
竖大拇指离散得意 wink：单眼闭合、嘴角单侧上挑，触发后保持约 3 秒回落P0
双手比心（两手指尖靠近）离散害羞：低头、腮红拉满、爱心粒子飘出（手机端隐藏此判定）P1
左右挥手（动作过程）离散小熊挥手回应；回应形态（整臂挥动或只抬小爪子）待 M2 半身形象定稿时定义P1
手掌快速靠近镜头离散吓一跳：后仰、汗滴、圆眼（彩蛋）P2

选取原则：全部手势都能由"手指伸直数量 + 关键点间角度/距离"直接算出，无需训练模型。形状相近、容易误判的姿势（数字 1–10、摇滚手势等）整批放弃。

判定规则（开发与验收依据）

手势判定条件
握拳五指全部屈曲（各指指尖到掌根距离低于阈值）
竖大拇指拇指伸直且其余四指屈曲；与握拳互斥，判定顺序在握拳之后
双手比心双手同时入画，两手拇指尖与食指尖相互贴近（指尖间距 < 手掌宽度的 30%）
左右挥手张开手掌状态下，1.2 秒内腕部横坐标往返摆动 ≥ 2 次；触发后冷却 2 秒
手掌快速靠近手部包围盒面积在 0.5 秒内增长 ≥ 60%；触发后冷却 3 秒
  • 互斥优先级：双手比心 > 竖大拇指 > 握拳 > 连续通道。离散表情锁定期间（如生气按住型），连续通道的嘴形/眉眼参数冻结，视线跟随保留。
  • 滞回：连续量的触发与解除阈值分离（如张开度 0.7 触发、0.5 解除），防止在阈值附近反复横跳。
  • 多手策略：非比心状态取置信度最高的一只手；换手时视线经弹簧插值平滑过渡，不瞬移。
  • 比心的手机端处理：手机端不启用比心判定。前置摄像头加单手举机的场景下，双手入画并让指尖贴近几乎无法做到，保留判定只会让用户摆了姿势却永远触发不了。
  • 方向语义：预览按镜像显示（照镜子），视线与歪头方向按镜像坐标跟随——用户手往自己的左边移，小熊视线往画面左侧移动。此语义在 M1 定死，不得中途更改。

04表情参数系统

小熊由六个图层组成（熊头罩与身体、脸盘、五官、腮红、头顶草莓、特效层）。所有表情都是同一套参数的不同取值，切换表情即插值到新参数，不换图片。

参数范围说明
pupilX / pupilY−1 ~ +1瞳孔偏移，视线跟随的核心
headTilt / headTurn−1 ~ +1歪头 / 转头
eyeShape圆点 / 弧线 / 眯缝 / 闭合眨眼、笑眼、wink 用同一参数表达；wink 触发期间覆盖自动眨眼
browAngle / browY−1 ~ +1眉毛角度与高低：倒眉生气、挑眉疑惑
mouthShape微笑 / 张嘴 / 嘟嘴 / 小圆 / 波浪五个嘴形，配 mouthOpen 连续开口度
blush0 ~ 1腮红透明度
bounce0 ~ 1身体弹性缩放（开心时弹跳）

表情档案（左侧导航展示，点击可手动切换）

表情参数组合要点触发方式优先级
待机视线缓慢游移、每 3–5 秒眨眼、呼吸起伏无手入画 3 秒后自动P0
好奇（有手入画）视线锁定手、眉毛微挑手入画自动P0

害羞低头、腮红满格、爱心粒子双手比心P1

离散表情保持方式（已确认：逐表情配置）

  • 按住型（生气）：手势保持多久，表情保持多久，松手后插值回落。
  • 点一下型（wink、害羞、吓一跳）：触发后固定保持约 3 秒再回落，保持期间忽略同手势重复触发。

05界面与布局

  • 左侧：竖排表情档案导航（中文为主 + 英文小字点缀），当前表情高亮；点击导航可手动触发对应表情，不依赖摄像头也能演示。点击触发的表情与手势触发走同一套参数插值，视觉一致；点击后摄像头通路不受影响，下一次手势正常接管。
  • 中央舞台：米白纸感背景，小熊居中占画面主体；顶部站点标题，杂志感排版——大留白、衬线点缀、编号页脚。
  • 右侧：识别调试面板——是否检测到手、当前姿势、视线/歪头/张合三个连续参数的实时条形、帧率。
  • 右下角：摄像头预览小窗（镜像显示），默认显示手部关键点，可一键折叠隐藏。
  • 首次进入：优雅的授权引导层，说明用途与隐私；引导层必须在浏览器权限弹窗之前出现，隐私说明首屏可见、不需滚动或展开。拒绝授权或设备不可用时进入"鼠标试玩模式"（滑块代替手势）：滑块控制视线、歪头、张合三个连续参数，离散表情经左侧导航点击触发，页面价值不打折。
  • 手机端布局（发布目标为"发给朋友"，此项为 M2 正式交付）：隐藏右侧调试面板；摄像头小窗默认折叠；表情导航改为底部横排或抽屉。竖屏下小熊仍居中主体。
排版参照说明：本项目的风格锚点是文字定义（米白纸感、大留白、衬线点缀、编号页脚）。前身"手势识别花朵"只到参考图阶段、未建成站点，无可直接照抄的页面；若 M2 排版时需要更具体的参照，由用户补充参考图。

06非功能需求

项要求
性能普通笔记本 30fps 起步；识别与渲染全在浏览器内，无网络往返延迟
隐私摄像头画面仅在本机内存中处理，不上传、不录制、不落盘，不写 localStorage / IndexedDB；关闭标签页即停止采集
兼容性桌面 Chrome / Edge / Safari 最新两个大版本；需 HTTPS 或 localhost 环境（浏览器对摄像头 API 的要求）。手机端（前置摄像头）为 M2 正式验收项
容错光线不足、手部分出画、多手入画时给出文字提示——手出画超过 1 秒提示、回画即消失，光线不足与手出画使用不同文案；拒绝授权、无摄像头、摄像头被占用、非 HTTPS 四种情况均自动进入鼠标试玩模式，每种情况给一行具体原因，不用通用文案；file:// 直接打开时 1 秒内将主界面替换为"需通过本地 HTTP 服务访问"的提示，附可复制的启动命令；页面不崩溃、不卡死
体积首次加载目标 20MB 内（模型 7.8MB + wasm 约 9.4MB，按实测资产核定），加载时显示进度与待机动画，进度按实际字节推进、不做假进度条

08技术方案概要

  • 识别：MediaPipe Tasks Vision 的 HandLandmarker（浏览器版），每帧输出 21 个手部关键点坐标；手势判定全部用关键点间的距离与角度计算，按第 03 节判定规则实现。
  • 渲染：角色用 SVG 图层绘制（底图位图 + 矢量五官），参数驱动，天然任意缩放不糊。
  • 平滑：所有参数经弹簧插值输出；离散手势经 0.2 秒稳定窗口确认；触发/解除阈值分离（滞回）。
  • 工程形态：纯 HTML + CSS + JS 三个文件 + 素材目录，无构建步骤；发布走 HTTPS 静态托管。
  • 本地开发方式：必须通过本地 HTTP 服务访问（如 python -m http.server）。直接双击打开（file://）时浏览器拦截 fetch，模型与 wasm 加载不了、摄像头不可用。

10风险与预案

风险预案
识别抖动导致表情闪烁0.2 秒稳定窗口 + 弹簧插值 + 滞回阈值三重保险；M2 阶段用真实使用录像回放调参
握拳与竖大拇指误判串扰判定顺序固定（拇指先于全拳），互斥逻辑写进状态机而非逐帧比较
三张素材角色形象不完全一致以定妆照为唯一主形象；表情表仅提取"形"的参考，不做逐帧对照
位图去白后边缘发灰去白后向内收缩 1px 收边；小熊本身粗描边，收缩不可见
手机端性能不足移动端降级为 15fps 识别 + 关闭粒子特效，保证基本互动
浏览器不支持摄像头 / 摄像头被占用自动进入鼠标试玩模式，文字说明原因，功能与展示价值保留
file:// 直接打开导致模型加载失败本地开发一律走 HTTP 服务；页面上线前用 M1 启动脚本验证

11已确认的决策（v0.2 定稿）

1. 主形象：头像版先行，半身版升级
M1 用头像版（表情最聚焦），M2 换半身带爪版，支撑挥手、比心的回应动作。
2. 离散表情保持：逐表情配置
生气=按住型；wink、害羞、吓一跳=点一下型（3 秒回落 + 冷却）。
3. 界面语言：中文为主 + 英文小字点缀
延续杂志感排版，不做中英切换。
4. 声音：P2，默认静音
M1/M2 不投入；若做，表情切换配极轻音效，点击开启（浏览器要求先交互才允许出声）。开关状态不持久化，刷新后回到默认静音。
5. 发布目标：发给朋友玩
手机端前置摄像头验证升级为 M2 正式验收项；不做"关于"页，M3 只需分享标题与缩略图正常。
